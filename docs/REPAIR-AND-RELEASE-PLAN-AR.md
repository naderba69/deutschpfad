## أوامر التحقق الحالية

تنفذ بالتتابع في CI؛ لا تشغّل `typecheck` بالتوازي مع build لأن Next قد يعيد توليد `.next/types`:

```bash
npm ci
npm run lint
npm run typecheck
npm test -- --run
npm run build
npm run typecheck
npm run test:e2e
```

`npm run audit:curriculum` أداة مساعدة للجرد وليست اعتماداً لغوياً. تتطلب E2E تثبيت متصفح Playwright في بيئة CI. سجّل إصدارات الأدوات ومخرجات الأوامر مع كل مرشح إصدار. افحص `npm audit` وقياسات Lighthouse كخطوات مستقلة حتى تضاف لها إعدادات ونطاق قبول واضحة.

## سجل الحالة عند كتابة الخطة

- خط البيئة: Node `v22.22.3` وnpm `10.9.8`؛ `npm ci` نجح بتاريخ 2026-11-04 مع lockfile، لكنه أبلغ 40 ثغرة (2 منخفضة، 27 متوسطة، 10 عالية، 1 حرجة).
- تدقيق الإنتاج `npm audit --omit=dev` أبلغ 19 ثغرة إنتاجية (2 منخفضة، 11 متوسطة، 5 عالية، 1 حرجة)؛ أبرزها Next.js المثبت 14.2.35. لم تحدث الاعتماديات؛ `npm audit fix --dry-run` تعطل بخطأ داخلي في npm، وأي ترقية major تتطلب خطة توافق واختبارات. هذا مانع إنتاج P1 إلى حين حلّه أو قبول خطر موثق.
- في هذه المرحلة أضيف `.nvmrc` وCI workflow، وأعيدت كتابة README وDEPLOYMENT لإزالة إعلانات الجاهزية والأعداد والخطوات التي لم تعد مثبتة. لم يُشغّل GitHub Actions بعد، لذا إعداد CI مضاف لكن نتيجته غير معروفة.
- تحقق محلي بعد `npm ci`: lint ناجح، typecheck ناجح، الوحدات 97 ملفاً و752/752 ناجحة، و`npm run build` نجح وأنتج 144 صفحة؛ `git diff --check` ناجح. هذه لا تعالج ثغرات الاعتماديات.
- Playwright: لم يُشغّل محلياً بسبب غياب Chromium؛ CI سيحاول تثبيته وتشغيله. لا توجد نتيجة CI حتى الآن.
- المحتوى والواجهات: تدقيق جزئي وإصلاحات متتابعة؛ لا مراجعة كاملة لكل ملفات/أسطر المشروع حتى الآن. الأمن/الخصوصية والأداء/النفاذية لا تزال غير مغلقة.
