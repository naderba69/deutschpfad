# دليل الإعداد والنشر — درب الألمانية

## 1) المتطلبات

- **Node.js 22.6 أو أحدث** (المحدَّد في `package.json` ⇒ `engines`، و`.nvmrc` = 22).
- npm (يأتي مع Node).
- Docker (اختياري، للنشر بالحاوية).

## 2) التشغيل المحلي للتطوير

```bash
npm ci
npm run dev        # http://localhost:3000
```

## 3) التشغيل في الإنتاج بدون Docker

```bash
npm ci
npm run build
PORT=3000 npm start    # يستمع على 0.0.0.0:$PORT (الافتراضي 3000)
```

`PORT` يُقرأ من البيئة؛ إن لم يُضبط يُستعمل 3000.

## 4) التشغيل بـDocker

```bash
docker build -t deutschpfad .
docker run -p 3000:3000 --env-file .env deutschpfad
```

- الصورة تستعمل **مستخدماً غير جذر** وإخراجاً مستقلاً (`server.js`).
- الملفات التالية **لا تدخل الصورة**: `node_modules` والاختبارات (`e2e`) والوثائق والسكربتات
  وكل ملفات `.env` (إلا `.env.example`). التفاصيل في `.dockerignore`.
- المنفذ داخل الحاوية `PORT` (الافتراضي 3000)؛ غيّره بـ`-e PORT=8080 -p 8080:8080`.

## 5) متغيرات البيئة

| المتغير | الغرض | إلزامي |
|---|---|---|
| `PORT` | منفذ الخادم | لا (3000) |
| `NEXT_PUBLIC_APP_URL` | العنوان العام للموقع (خريطة الموقع والدعوات) | لا |
| `GEMINI_API_KEY` | مفتاح Gemini — **يبقى على الخادم فقط** | لا |
| `GROQ_API_KEY` / `OPENROUTER_API_KEY` | مزودون بديلان | لا |
| `GEMINI_MODEL` / `GROQ_MODEL` / `OPENROUTER_MODEL` | تغيير النموذج | لا |
| `LLM_SERVER_MODE` | `1` لتفعيل المعلم الذكي من الخادم | لا |
| `LLM_COUNTER_REST_URL` / `LLM_COUNTER_REST_TOKEN` | عدّاد مشترك للحد اليومي | لا |
| `NEXT_PUBLIC_LLM_DAILY_LIMIT` | حد الطلبات اليومي | لا |
| `TRUST_PROXY` | `1` خلف وكيل موثوق ليُقرأ IP من `x-forwarded-for` | لا |

**قواعد الأمان:**
- لا تضع أي مفتاح في ملفات يُرفع إلى Git. استعمل `.env` المحلي أو أسرار المنصة.
- مفتاح Gemini يُرسل في ترويسة `x-goog-api-key` ولا يظهر في الروابط.
- **حد المعدل**: 45 طلباً في الدقيقة لكل IP على `/api/llm`. مع `TRUST_PROXY=1` تُقرأ IP الحقيقية؛
  بدونه كل الطلبات تُحسب كمجموعة واحدة. الحد محفوظ في ذاكرة كل نسخة من الخادم، فالنشر بعدة نسخ
  يعطي حداً لكل نسخة.

## 6) خلف وكيل عكسي

ضع الوكيل أمام الحاوية أو الخادم، واضبط `TRUST_PROXY=1` **فقط** إذا كان الوكيل
يكتب `x-forwarded-for` بنفسه ويمسح ما يرسله العميل. وإلا فالعميل يستطيع انتحال IP.

## 7) الاختبارات قبل النشر

```bash
npm run typecheck
npm run lint
npm test
npm run build
```
