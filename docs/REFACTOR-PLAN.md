### المرحلة 1 — شبكة الأمان (CI) ✅ مُنجزة ومُتحقَّقة بتشغيل حقيقي
- **الهدف:** لا تدخل دفعة مكسورة إلى الفرع، ولا يُكتشف عيب بعد شهر.
- **التنفيذ النهائي:** `.github/workflows/ci.yml` بوظيفتين **تعملان بالتوازي** (بلا `needs`
  فالزمن = أطول وظيفة لا مجموعهما):

  2. بناء + 217 اختبار متصفح على نسخة إنتاجية، مع رفع آثار الفشل.
  و`npm run verify` محلياً ينفّذ نفس فحوص الوظيفة 1.
- **الدليل (لا ادّعاء):** التشغيل `38461731991` — `completed/success`، والوظيفتان ناجحتان
  على GitHub نفسه.
- **دروس من التشغيل الحقيقي (موثّقة داخل ملف الـ workflow):**
  1. `actions/upload-artifact` **يستبعد الملفات المخفية افتراضياً**؛ محاولة نقل `.next`
     بين الوظيفتين أخفقت بـ «Artifact not found» → أُلغي النقل وكل وظيفة تبني نسختها
     (إزالة coupling هش خير من ترقيعه).
  2. لنفس الالتزام كان GitHub يشغّل الوظائف مرتين (حدث `push` وحدث `pull_request`) →
     وُحّدت مجموعة التزامن على مفتاح الالتزام نفسه فأُلغي التكرار.
  3. أُحدّثت إصدارات الأدوات (checkout/setup-node/upload-artifact) لإزالة تحذير
     إهمال Node 20 في بيئة التشغيل، وأُضيفت شارة CI إلى `README`.
- **معيار الإغلاق:** تشغيل أخضر مُتحقَّق منه على GitHub ✅ · أمر تحقق واحد محلياً ✅ ·
  مَنع تكرار التشغيل لنفس الالتزام ✅.
