## 3. التصميم والتنظيم

**نقاط القوة:**
- Design System حي (`/design-system`) يوثّق الألوان والخطوط والمكونات واتجاهات RTL/LTR.
- انضباط RTL كامل: صفر `text-left/right`، صفر `ml-/mr-` فيزيائية — كل شيء بخصائص منطقية.
- النص الألماني مغلّف بمكون `LangDe` (dir=ltr lang=de خط Inter) — 502 استخداماً لـfont-de.
- أزرار الأيقونات وحدها تحمل aria-label؛ الصور كلها بـalt؛ لا console.log ولا أسرار في الكود.
- تنقل ثلاثي الطبقات: header (سطح مكتب) + شريط سفلي (جوال) + قائمة جانبية — مع aria-current.

**ملاحظات:**
- الرئيسية الذكية تومض بفراغ أثناء تحميل الملف الشخصي (div فارغ) — يُفضَّل هيكل عظمي.
- 12 رابطاً داخلياً كانت `<a>` بدل Next Link (إعادة تحميل كاملة) — **أُصلحت في هذه الجولة**.

## 4. البيداغوجيا التفاعلية

**نقاط القوة:**
- الدرس: أهداف → نظرية → تمارين تفاعلية (14+ لكل بنك) → اختبار مصغر → كتابة → قراءة/استماع → بطاقات → مراجعة متداخلة → إكمال مع تقدم تلقائي قابل للإلغاء.
- المرجع النحوي: بحث + فلترة + خريطة ذهنية + غوص عميق.
- مداخل متعددة: مسار تعلم، اختبار تحديد مستوى، درس تجريبي، تحدٍّ يومي، خمس دقائق.
- إشارات صادقة: لا ادعاء CEFR رسمي في التذييل والملخصات؛ Can-Do مؤشر داخلي فقط.
- تحفيز: جواهر، شارات، كلمة أستاذ بشخصية، تحديات يومية.

**ملاحظات:**
- حقول أدوات الذكاء الاصطناعي كانت placeholder-only (ليست label لقارئات الشاشة) — **أُصلحت بـaria-label في هذه الجولة** (7 ملفات).
- البريد في التذييل `info@deutschpfad.app` لا يطابق نطاق النشر `deutschpfad.vercel.app` — يُرجى تأكيد مالك المنتج إن كان مقصوداً.
