# ملاحظات مراجعة A2-02

**النطاق:** تدقيق آلي/تحريري للمحتوى المرتبط بدرس `Beim Arzt` وموارده المحددة في بيانات الدرس. ليست مراجعة بشرية ولا اعتماداً رسمياً من CEFR أو Goethe.

## ما فُحص

- تعريف الدرس `src/data/lessons/a2/a2-02.ts` وملفات المحتوى `intro.ts` و`theorie.ts` و`skills.ts` و`practice.ts` و`cards.ts`، واختباراه `a2-02.test.ts` و`a2-02/listening-audio.test.ts`.
- موارد الدرس المعلنة: الحوار `a2-01-arzt` وملفات MP3 الستة، والقصتان `a2-beim-arzt` و`a2-zahnarzt`، إضافة إلى حوار التدريب التكميلي `dl-arzt`.
- اختبارات الحوار والقصص والموارد المرتبطة وملفات الصوت. راجعت صياغات مختارة ذات أثر صحي أو نحوي بمراجع رسمية/لغوية، لا كل جملة في الألمانية مراجعة مستقلة.

## الإصلاحات وأثرها على المتعلم

- وُسِمت سيناريوهات الصحة بأنها خيالية للتدريب وليست تشخيصاً أو نصيحة طبية. في حوار `dl-arzt` أزيلت توصية الجرعة العامة «ثلاث مرات يومياً» ومدة العلاج «خمسة أيام»، واستُبدل بهما توجيه لقراءة نشرة الدواء أو سؤال مختص، مع نهاية تحيل إلى الطبيب عند عدم التحسن. يقلل ذلك خطر أخذ مثال لغوي على أنه تعليمات علاجية.
- عُدّلت قصة الطبيب لتذكر الراحة والبقاء في المنزل بدلاً من تعميم شرب الكثير من السوائل كعلاج؛ ووُئم سؤالها وخياراته مع النص.
- ضُبطت معلومات البطاقة الصحية والإحالة الطبية والإجازة المرضية في الشرح كي لا تُعرض ترتيبات التأمين أو الإحالة أو إبلاغ صاحب العمل على أنها تنطبق بلا استثناء.
- صُحح شرح `Kopfschmerzen`، وشرح الأفعال الانعكاسية والتمييز بين Dativ/Akkusativ، وشرح `sollten` في النصيحة، ومشتت `Du musst zum Arzt gehen wollen` ليبيّن أنه تركيب ممكن بمعنى «يجب أن تريد الذهاب» لا نصيحة «ينبغي أن تذهب».
- أضيفت إفصاحات عن TTS المتصفح في مقاطع الاستماع المناسبة، وحُذف ادعاء ثبات هوية الصوت حيث لا تدعمه البيانات. أُضيفت اختبارات تحرس الإفصاحات وحدود الادعاء.
- ضُبط مستوى الإشارة لملف `public/audio/dialogues-a2/a2-01-arzt-1.mp3`: ارتفع RMS من ‎−37.1 إلى ‎−21.0 dBFS، والذروة بعد التعديل ‎−3.1 dBFS. اجتازت مقاطع A2-02 الاثنا عشر (ستة ملفات الدرس وستة ملفات الحوار) حد فحص الإشارة المحدد ‎−23 dBFS دون clipping مرصود.

- gesund.bund.de، البطاقة الصحية الإلكترونية: https://gesund.bund.de/en/die-elektronische-gesundheitskarte — نطاق البطاقة مرتبط بالتأمين القانوني، فلا يصح التعميم على الجميع.

- gesund.bund.de، الإجازة المرضية الإلكترونية: https://gesund.bund.de/en/die-elektronische-arbeitsunfaehigkeitsbescheinigung-eau — الإرسال الرقمي لا يلغي واجب العامل بإبلاغ صاحب العمل، ولا يتلقى صاحب العمل التشخيص.
- gesund.bund.de، نشرة الدواء: https://gesund.bund.de/en/arzneimittel-beipackzettel — تتضمن الاستخدام والجرعات والتحذيرات والتداخلات، وتُطلب المشورة عند الالتباس.

هذه المراجع تدعم تعديلات محددة، ولا تعني مراجعة طبية أو لغوية شاملة أو اعتماداً لمستوى CEFR/Goethe.

## التحقق المنفذ

- اختبارات الدرس والصوت وموارده: **8 ملفات اختبار، 65 اختباراً ناجحاً**.
- المجموعة الكاملة: `npm test` — **216 ملف اختبار، 1384 اختباراً ناجحاً**.
- `npm run typecheck` — ناجح.
- `npm run lint` — ناجح، دون تحذيرات أو أخطاء ESLint.
- `npm run audit:lessons` — اكتمل بنتيجة صفر ملاحظات (فحص المصادر السابقة للمراجعة).
- `git diff --check` — ناجح.
- فحص الصوت عبر `scripts/audio-signal-audit.py` قاس فك الترميز ومستوى الإشارة والذروة ومؤشرات القصّ فقط.

## حدود الدليل والنواقص المفتوحة

- لم تُقيّم وضوح مخارج الحروف أو طبيعية الأداء أو اللهجة أو السرعة، ولم تُقارن ملفات الطبيب بالتفريغ النصي جملةً جملة. فحص فك الترميز وRMS/الذروة لا يثبت جودة النطق أو مطابقة الصوت للنص.
- مصدر ملفات MP3 الستة لحوار الطبيب غير موثق؛ لا يُحسم هل هي تسجيل بشري أم TTS. إفصاح التطبيق لا يعوض التحقق من المصدر.
- الاختبارات تتحقق من بنية البيانات ومفاتيح محددة وإفصاحات بعينها، ولا تثبت خلو جميع مواد الدرس والموارد من كل خطأ أو صلاحيتها الطبية.
- لم يُجر تدقيق رسمي لمستوى CEFR أو مطابقة Goethe، ولا توجد مراجعة بشرية في هذه الجولة.
- لم يُشغّل `npm run build` ضمن هذه الجولة؛ نجاح typecheck وlint والاختبارات لا يضمن نجاح الإنتاج أو العرض داخل المتصفح.

**الحالة:** اكتمل التدقيق ضمن النطاق والفحوص المذكورة فقط؛ لا يعني مراجعة بشرية أو اعتماداً رسمياً أو اكتمال تدقيق المشروع كله.
