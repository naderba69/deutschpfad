## ③ إعادة التصميم الاحترافية للواجهة الرئيسية

**قبل**: لوحة الرحلة كانت مكدسة العناصر بلا ترتيب أكاديمي — كل البطاقات متتالية
بلا أقسام إرشادية، وبطاقة استئناف مزدحمة بأزرار كثيرة.

**بعد — تسلسل أكاديمي صريح بستة أقسام مرقمة** (في `learner-journey.tsx`):

```
① وضعك الآن      ← 4 بطاقات إحصائية: المستوى، التقدم الكلي، السلسلة، XP
② خطوتك التالية  ← CTA واحد كبير: رقم الدرس + عنوانه + المدة + زر «تابع الدرس» + شريط تقدم
③ مسارك          ← 4 بطاقات مستويات (A1→B2) مع أشرطة وختم — كل بطاقة رابط للمركز
④ جلسة اليوم      ← اقتراحاتك الذكية + تحدي اليوم
⑤ تطورك          ← دوري أسبوعي + نمو + مصفوفة إتقان
⑥ أدواتك وتخصيصك ← روابط سريعة (مسار/اختبار/صوت/تقرير) + خطة + تفضيلات + نسخ + دعوة
```

**لماذا هذا الترتيب؟** لأنه يقلد منطق الفصل الدراسي: «اعرف وضعك ← افعل خطوتك التالية ←
اعرف أين تمضي ← مارس اليوم ← راجع تطورك ← استخدم أدواتك». كل قسم بعنوان رقمي
(١-٦) ووظيفة واحدة — **لا توهان**.

**الريسبونسف**: الشبكات تتحول عمودياً على الجوال (grid-cols-2→1، lg:grid-cols-4→2→1)
وكل البطاقات تنضغط بأناقة بلا فيضان (مثبَّت آلياً).

### 🔴 إصلاح «أكمل الدرس» لا ينقل للدرس التالي (شكوى المستخدم)

  **يُنتقل تلقائياً لصفحة الدرس التالي خلال 2.5 ثانية**. (لو كان الدرس الأخير:
  «🏆 أتممت المسار» ورابط امتحان الختم).
