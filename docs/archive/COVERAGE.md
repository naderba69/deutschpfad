## ثانياً: تغطية المناهج — كتاب Goethe/Telc/Menschen كاملاً

### أ) المهارات الخمس (كما في الامتحان الرسمي)
| المهارة | الغلاف | الأقسام |
|---|---|---|
| **القراءة (Lesen)** | ✅ | 16 نصاً متدرجاً A1→B2 + مكتبة قراءة + أسئلة فهم |
| **الاستماع (Hören)** | ✅ | 16 مقطعاً + مشاهد استماع في كل درس + مكتبة hoeren |

| **التحدث (Sprechen)** | ✅ | امتحان شفهي كامل + تدريب نطق + معلّم صوتي |
| **القواعد (Grammatik)** | ✅ | 40 سؤالاً + مرجع نحوي + جداول تصريف + أفعال شاذة |

### ب) قواعد كل مستوى (مطابقة لمنهج Goethe/Telc/Menschen)

**A1** — sein/haben، السلسلة الذهبية، الأدوات، Akkusativ، الأفعال المنفصلة، الناقصة الأولى (kann/möchte/muss)، الماضي الأول (war/hatte)، W-Fragen + V2، النفي، الأرقام والوقت، Imperativ.

**A2** — Perfekt (haben/sein)، Wechselpräpositionen، Dativ، Komparativ/Superlativ، weil/dass/wenn/ob، الأفعال الناقصة كاملة، Reflexive Verben، الروابط (deshalb/trotzdem)، إضافات: بنك، بنوك، مواصلات، خدمات.

**B1** — Genitiv، Relativsätze، Präteritum كامل + Plusquamperfekt، Passiv + man، Konjunktiv II (würde/hätte/wäre) + الماضي، Adjektivdeklination، الروابط المزدوجة، الجمل الزمنية (als/wenn/während/bevor/nachdem/bis) + obwohl، Nomen-Verb-Verbindungen، n-Deklination، Infinitiv mit zu.

**B2** — Konjunktiv I (نقل الكلام)، Passiv بكل أنواعه (Zustandspassiv + Modalverben + Ersatzformen)، Partizipialattribute، Nominalisierung، Futur II، Verben mit Präpositionen، روابط متقدمة (indem/anstatt...zu/ohne...zu/es sei denn/folglich/demnach) + Modalpartikeln، Erörterung أكاديمية، الاستخدام الذاتي للناقصة (تخمين).

### ج) المواضيع (مطابقة لكتب Menschen/Telc)
- **A1**: التعارف، العائلة، الطعام، السكن، اليوم، الهوايات، التسوق، الملابس، المواعيد، المهن، المدينة، الطقس.
- **A2**: السفر، الصحة، المطعم، السكن، العمل، الإعلام، البنك، المواصلات، المناسبات، المدرسة، الخدمات، العلاقات.
- **B1**: التعليم، العمل، البيئة، الإعلام، الصحة، الثقافة، السياسة، التقنية، التطوع، المستقبل + الوطن/الهجرة.
- **B2**: العلوم، الاقتصاد، القانون، الأدب، علم النفس، المهنة، الفلسفة، اللغات، سوق العمل، الدراسة في ألمانيا + العمل المرن.

### د) بنية الدرس (10 مكونات — أغنى من أي كتاب)
أهداف ← تمهيد ← نظرية (مع أمثلة ومقارنة بالعربية وحيل) ← استماع ← نطق ← كتابة ← تمارين تفاعلية ← أخطاء شائعة ← اختبار مصغّر ← بطاقات ← **ملخص PDF**.

### هـ) التقويم (مطابق لشكل الامتحان)
- تحديد مستوى (سريع/تشخيصي) ← اختبارات وحدات ← اختبارات مستويات ← **امتحان ختم** لكل مستوى ← **محاكاة امتحان B2 كاملة** ← امتحان شفهي.

## ثالثاً: ملاحظة شفافة (ما لا يغطيه أي كتاب — وما نغطيه نحن)

كتب Goethe/Telc/Menschen تنقلك من A1→B2 بتمارين وحوارات — ونحن نطابق ذلك **ونضيف**:
- ترجمة عربية كاملة + مقارنات لغوية بالعربية (أهم ما ينقص الكتب الأصلية للمتعلم العربي)
- نطق مخصص لأخطاء العربي (أصوات ei/ie/ch/r…) في كل درس
- حيل للحفظ (Eselsbrücken) بالعربية
- لقطات ثقافية عن الحياة في ألمانيا (Bürgeramt، Hausordnung، Trinkgeld…)
- نظام مسار متسلسل + مراجعة SM-2 + تقدم يُحفظ

> **الخلاصة**: منصة واحدة مجانية صفر دولار تغطي كل تفاصيل المنهاج الأربعة بمستوى كتاب معهد — وتفوقه للمتعلم العربي بالترجمة والنطق والترتيب.
