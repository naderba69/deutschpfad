# 📘 المراجعة الكاملة للمشروع — DeutschPfad (درب الألمانية)

> **منصة عربية مجانية 100% لتعليم اللغة الألمانية من A1 إلى B2**
> بمنهجية معهد غوته (Goethe-Institut) ومعايير CEFR — تصمم لتنافس المنصات العالمية
> في المحتوى والتصميم والمنهجية وتجربة المستخدم.

## 1) ما هو المشروع؟ (بسطر واحد)

منصة ويب تفاعلية كاملة (PWA) تحوّل المتعلم من «صفر» إلى «إتقان B2» عبر **مسار منهجي مقفل آلياً**، يدمج كل مهارات اللغة (قراءة، استماع، كتابة، تحدث، قواعد) بأسلوب «الأستاذ الحي» — مجانية بالكامل، بلا حسابات، وتُحفظ بيانات كل مستخدم على جهازه.

## 3) كيف يعمل؟ (آلية التشغيل خطوة بخطوة)

### 🔐 3.1 أول زيارة (الدخول)
1. **الترحيب**: «أستاذك الخبير» يخاطبك من أول لحظة + بطاقة «أهلاً بك، رحلتك من A1 حتى B2»
2. **أدخل اسمك** (يُحفظ في متصفحك)
3. **اختر نقطة البداية**: 🎯 «حدّد مستواك» (اختبار 15 سؤالاً) **أو** 🚀 «ابدأ من الصفر»
4. **يبدأ المسار**: أول درس غير مكتمل يصبح «التالي» — آلياً

### 🧭 3.2 المسار (الترابط الآلي)
```
A1-01 (مفتوح) ← تُتمّه ← يفتح A1-02 ← … ← A1-14
← تُتمّ كل A1 ← يظهر «امتحان ختم A1» ← تجتازه ← يفتح A2
← … ← B2-10 ← ختم B2 ← «أتممت المنهاج كاملاً»
```
- **الدروس تُقفل تسلسلياً** 🔒 (لا تفتح التالي قبل إتمام السابق)
- **المستوى التالي يُقفل بالختم** (لا يفتح قبل اجتياز امتحان الختم)
- **الحفظ**: تعود من حيث توقفت (المرحلة + القلوب + النقاط)

### 🎓 3.3 داخل كل درس (التدفق التفاعلي — 10 مراحل)
1. **الافتتاح**: سؤال تحفيزي + أهداف الدرس + «التحدي الزمني» (اختياري)
2. **القواعد 1-4**: شرح قصير + أمثلة قابلة للنطق + زر «🔊 استمع للشرح»
3. **التدريب**: تمارين تتكشف واحداً واحداً — حلّ التمرين يكشف التالي
4. **الاستماع**: حوار بأزرار نطق + «وضع الامتحان» (نص مخفي) + «استمعت وفهمت»
5. **الإنتاج**: اكتب جملة أصلية ← تُقيَّم فوراً بمعايير Goethe
6. **المحادثة**: حوار محاكاة بجمل الدرس
7. **الاختبار**: أسئلة سريعة (أجب عن الكل للمتابعة)
8. **أخطاؤك اليوم**: الأخطاء تُعاد تلقائياً لتثبيتها
9. **الإنجاز**: بطاقة نقاط (XP + قلوب + مكافآت سرعة)
10. **متابعة**: شريط سفلي ثابت (السابق/التالي)

### 🎮 3.4 نظام اللعب (يمنع الملل)
- **5 قلوب ❤️**: الخطأ يخسر قلباً — تنتهي تعيد المحاولة
- **نقاط XP ⚡**: +10 للصواب، +5 مكافأة سرعة (تحدي 15 ثانية)
- **مؤثرات** ✅/❌ متحركة
- **سلسلة أيام 🔥** + رسائل تشجيع حسب السلسلة

### 📊 3.5 التتبع والتقويم
- **تطورك**: أشرطة المستويات الأربعة + دقة التمارين + الشارات + XP
- **اقتراحات اليوم**: مراجعة ذكية حسب أخطائك + مراجعة قبل النسيان + تنبيه الغياب
- **اختبارات**: تحديد مستوى + وحدات + مستويات + **محاكاة Goethe لكل مستوى** (بتكيّف) + ختم + شفهي + **محاكاة B2 الكاملة**
- **تقرير PDF** + **شهادات إتمام**

### 💾 3.6 الحفظ والخصوصية
- كل البيانات في **متصفح المستخدم** (IndexedDB) — بلا خادم، بلا حسابات
- **تصدير/استيراد**: نقل تقدمك بين الأجهزة
- **مجانية 100%**: لا اشتراكات، والميزات الذكية تعمل بدون مفاتيح (LLM اختياري مجاني)

## 4) المميزات (لماذا تتفوق)

### 🧑🏫 بيداغوجيا (منهجية)
- **مسار مقفل آلياً** — لا قفز، تعلّم تسلسلي صارم
- **التدفق المتكشف**: المحتوى يظهر مع تفاعلك (لا كتل مكدسة)
- **الإنتاج الإجباري**: تكتب وتتحدث جمل أصلية (الإتقان لا التلقي)
- **الخطأ يُصحَّح**: أخطاؤك تُعاد تلقائياً + تلميحات متدرجة
- **النطق مقيّم فورياً**: انطق أي كلمة ← درجة 0-100 + تصحيح

### 🎨 تصميم (تجربة مستخدم)
- **هيدر منظم**: 5 عناصر فقط + 4 قوائم منسدلة (لا 30 رابطاً)
- **مراكز مستويات** معاصرة (ترويسة متدرجة + خريطة دروس مقفولة)
- **رئيسية ذكية**: المسجّل يرى مساره مباشرة
- **متجاوب** (جوال/حاسوب) + **وضع ليلي** + حركات ناعمة + **RTL كامل**

### 🎮 تحفيز
- قلوب + نقاط + سلسلة + تحدٍ يومي + شارات + رسائل تشجيع

### 🔒 تقني
- **127+16 اختباراً آلياً** (حماية من الانحدار)
- **PWA**: يعمل دون إنترنت (بعد الزيارة)
- **مجاني 100%** + **خصوصية كاملة** (بلا خادم)

## 5) ما يبقى (بصراحة تامة)
- **LLM اختياري**: المعلّم الافتراضي وأدوات الذكاء تعمل بدون مفاتيح (مخفية عند غيابها) — تفعيلها بمفاتيح مجانية يضيف: معلّم صوتي، توليد تمارين، تصحيح كتابة أعمق.
- **سحابة (اختياري مستقبلاً)**: حالياً التقدم محلي؛ المزامنة عبر الأجهزة تحتاج حساباً (يخالف «بلا حسابات» الحالية).

## 6) الخلاصة

**DeutschPfad** منصة متكاملة منضمة: مسار منهجي مقفل + تدفق تفاعلي لا يملّ + تقويم حقيقي (نطق/كتابة/اختبارات) + تحفيز ألعاب + خصوصية تامة + مجانية 100%. **هدفها النهائي: تلميذ يتقن اللغة، لا تلميذ لُقِّنها.**
