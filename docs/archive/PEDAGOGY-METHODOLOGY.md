> وثيقة التصميم التربوي: كيف نجعل المتعلم «يتقن اللغة» لا «يُلقَّنها» فقط
> تحديث: 2026-08-14

---

## 1️⃣ المبدأ التربوي المركزي

**المسار مبني على التعلّم الحلزوني (Spiral Curriculum — Bruner):**
كل مفهوم يُقدَّم أولاً ببساطة، ثم يُعاد في مستوى أعلى من التعقيد، فيترسّخ في الذاكرة
طويلة المدى. مثال حي في المنصة:
- الفعل `werden` يظهر في A1 (يصبح: الطقس) ← في A2 (المستقبل القريب) ← في B1 (Futur I) ← في B2 (Futur II + Passiv)

---

## 2️⃣ الإطار المرجعي: CEFR + Goethe

| المستوى | CEFR | ساعات تقريبية | ماذا يعني «أتقنته» |
|---|---|---|---|
| A1 | مبتدئ | 80–100 ساعة | أستطيع التعارف والطلب وفهم جمل يومية بطيئة |
| A2 | أساسي | 180–200 ساعة | أستطيع الماضي البسيط، السفر، المطعم، وصف يومي |
| B1 | متوسط | 350–400 ساعة | أستطيع الجمل المركّبة، الرأي، التخطيط، تجربة السفر |
| B2 | متقدم | 550–650 ساعة | أستطيع اللغة الرسمية، النقاش المجرد، الكتابة الأكاديمية |

كل مستوى ينتهي بـ**امتحان ختم (Seal)** يحاكي Goethe — لا تنتقل للمستوى التالي إلا بعد اجتيازه.

## 3️⃣ البنية الداخلية للدرس (الدورة التعلمية الكاملة)

كل درس يتبع **دورة تعلم من 9 مراحل** (نموذج التعلم الخماسي المحسّن):

```
الافتتاح (تشويق + أهداف) ← القواعد (شرح متدرج + مثال) ← التدريب (تمرين يتكشف بعد سابقه)
← الاستماع (فهم سمعي) ← الإنتاج (كتابة موجهة) ← المحادثة (حوار محاكى)
← الاختبار (3 أسئلة تقييم) ← أخطاؤك (إعادة الأخطاء حتى التثبيت) ← الإكمال (احتفال + بطاقة)
```

**لماذا هذا التسلسل؟** لأنه يتبع نظرية **التجهيز المعرفي (Cognitive Load Theory)**:
كل مرحلة تُجهّز الدماغ للمرحلة التالية — الشرح ثم التطبيق ثم التلقين ثم الإنتاج الحر.

## 4️⃣ المبادئ العلمية المطبقة (ولماذا)

| المبدأ | مصدره العلمي | تطبيقه في المنصة |
|---|---|---|
| **التكرار المتباعد** | Ebbinghaus / SM-2 | مراجعة الجمل والبطاقات بجداول SM-2 |
| **التدرب المتدرج (Scaffolding)** | Vygotsky (ZPD) | التمارين تتكشف تدريجياً + تلميحات متدرجة |
| **التغذية الراجعة الفورية** | Behaviorism | شرح «لماذا» بعد كل إجابة (في كل تمرين) |
| **التعلم النشط** | Piaget | المستخدم ينتج لا يقرأ فقط: كتابة، نطق، ترتيب، حوار |
| **التقييم التكويني** | Bloom | الاختبارات الصغيرة داخل كل درس ترصد الفهم لحظياً |
| **دفتر الأخطاء** | Error Analysis (Corder) | الأخطاء تُصنّف وتُعالج كبيانات تعلم لا كفشل |
| **اللعبية (Gamification)** | Malone & Lepper | قلوب، XP، دوري، جواهر — تحفز الاستمرارية لا التشتت |

## 5️⃣ المهارات الأربع + مهارة خامسة (النظام الأكاديمي)

| المهارة | أين تُدرَّب؟ | كيف تُقاس؟ |
|---|---|---|
| الاستماع Hören | مرحلة الاستماع + مكتبة الاستماع + القصص | أسئلة فهم بعد كل مقطع |
| القراءة Lesen | القراءة المتدرجة + القصص | أسئلة فهم + مطابقة عناوين |
| التحدث Sprechen | النطق المقيّم + المحادثة المحاكاة + الظل الصوتي | تقييم فوري 0–100 + تقييم ذاتي |
| الكتابة Schreiben | الإنتاج اللغوي + مقيّم الكتابة + الإملاء | تصحيح آلي بقواعد Goethe |
| **التفكير اللغوي** | تمارين التحويل (الجمع/الزمن/المجهول) | فهم القواعد لا حفظها |

## 6️⃣ ما الذي يُكمل المسار (قائمة الأولويات القادمة)

### مستوى «النظام» (منهجية صارمة)
1. **خريطة مسار بصرية متعرجة** (Path) لكل مستوى: عقدة لكل درس + فروع للمراجعات والاختبارات
2. **مراجعة أسبوعية مجدولة إلزامية**: بعد كل 3 دروس تظهر «مراجعة تراكمية» (نموذج إعادة تثبيت)
3. **بوابات تقدم (Gates)**: لا يُفتح درس جديد قبل إتمام سابقه + مراجعة قصيرة (موجود جزئياً)
4. **تقرير تقدم أسبوعي تلقائي**: رسالة تلخص ما تعلمته، أخطاءك، سرعتك — أسبوعياً
5. **خطة دراسية شخصية تنبؤية**: تحسب متى ستصل لكل مستوى حسب وتيرتك الفعلية

### مستوى «المحتوى» (تثري التجربة)
6. **بودكاست تعليمي مبسّط** لكل مستوى (نص مسموع + أسئلة) — الاستماع الممتد
7. **سلسلة «حياة يومية»** (Vlogs نصية): مقاطع قصيرة عن الحياة في ألمانيا + أسئلة
8. **نصوص ثقافية (Landeskunde)**: أعياد، عادات، مدن — بعد كل وحدة
9. **مهام كتابة متدرجة**: من جملة ← فقرة ← رسالة ← مقال حسب المستوى
10. **قصص إضافية لكل مستوى** (الهدف: 12 قصة لكل مستوى = 48 قصة)

### مستوى «القياس» (يثبت الإتقان)
11. **اختبارات دورية تصاعدية**: كل 5 دروس اختبار تراكمي + كل مستوى امتحان ختم (موجود)
12. **شهادة إتقان قابلة للتحميل** لكل مستوى (PDF بكل الإحصائيات)
13. **لوحة «كفايات CEFR»**: أشرطة لكل مهارة توضح «أنت هنا» بدقة
14. **مؤشر «الإتقان» لكل مفهوم نحوي**: مثلاً «الجنس النحوي: أتقنته 87%»

## 8️⃣ كيف نعرف أن المتعلم «أتقن» لا «لُقِّن»؟

**علامات الإتقان الحقيقي** (نستطيع قياسها الآن):
1. يستطيع **إنتاج** جملة صحيحة لم يرها من قبل (الإنتاج الحر المقيّم) ✓ موجود
2. يستطيع **تحويل** الجمل (زمن/جمع/مجهول) بلا حفظ ✓ موجود
3. نطقه يُفهم من متحدث أصلي (الدرجة ≥ 80) ✓ يُقاس
4. أخطاؤه المتكررة **تختفي تدريجياً** من دفتر الأخطاء ✓ يُتتبع
5. يجيب عن أسئلة فهم **لم يُدرَّب عليها** (في القصص الجديدة) ✓ مضمّن
6. يحافظ على **الطلاقة** (سرعة الإجابة في التحدي الزمني) ✓ يُقاس

> **الفلسفة:** نحن لا نعلّم الألمانية — نُدرّب الدماغ على نظامها. كل تمرين هو
> «تطبيق لغة» لا «اختبار حفظ». هذا هو الفرق بين منصة تُنتج تلاميذ ومنصة تصنع متحدثين.
