# بروتوكول المراجعة بالمصادر والاختبارات والنموذج

**الحالة:** قاعدة العمل المعتمدة للمراجعات اللاحقة. لا يفترض هذا البروتوكول وجود مدقق بشري أو مختص متاح، ولا يجعل الحصول على مراجعة بشرية شرطاً لإغلاق بند.

## طريقة المراجعة

تُجرى المراجعة بواسطة وكيل Arena باستخدام أدوات المستودع والاختبارات، والمعرفة اللغوية العامة للنموذج، والبحث عن مراجع إلكترونية موثوقة عند الحاجة. ويجب تسجيل ما فُحص بالفعل، لا وصف النية بأنها تحقق.

لكل درس، تُنفذ حزمة واحدة منظمة:

1. قراءة جميع ملفات الدرس الفرعية والبيانات الوصفية والاختبارات، مع استخراج أهدافه ومهامه ومفاتيحه وخياراته وتفسيراته.
2. فحص آلي بنيوي، ثم تدقيق محتوى بنداً بنداً: صحة الألمانية والعربية، طبيعية العبارة، مطابقة الإجابة للسياق، جودة المشتتات، دقة الشرح، واتساق الهدف مع ما تقيسه المهمة.
3. عند وجود معلومة قابلة للتحقق أو التغير (لغة معيارية، صوتيات، امتحان، قانون، صحة، مال، إحصاء أو خدمة): البحث عن مصادر أولية أو رسمية حديثة، وتسجيل الرابط وتاريخ الاطلاع والعبارة التي يسندها المصدر. تُستخدم المراجع اللغوية والمؤسسية المناسبة للموضوع، لا مجرد صفحات عامة.
4. مقارنة الادعاء بالمصدر وبسياق الدرس. إذا تعارضت المراجع أو لم يظهر دليل كافٍ، تُضيّق العبارة أو تُصاغ على أنها تقريب/مثال أو تُسجل غير محسومة؛ لا يُملأ الفراغ بالتخمين.
5. إصلاح البنود المؤكدة في حزمة متماسكة، وإضافة اختبارات تمنع عودة الأخطاء القابلة للفحص آلياً.
6. تشغيل الاختبارات ذات الصلة ثم الأدوات الأوسع الملائمة، وتسجيل النتائج الفعلية والحدود التي بقيت.

## درجات الدليل

- **موثق بمصدر:** رابط حالي لمصدر أولي/رسمي أو مرجع موثوق، مع مطابقة مباشرة للادعاء.
- **راجعه النموذج ضمن السياق:** تدقيق لغوي/تعليمي بالمعرفة اللغوية للنموذج ومقارنة أمثلة ومصادر متاحة؛ مفيد لاكتشاف الأخطاء، لكنه ليس شهادة اعتماد أو ضماناً لانعدام الخطأ.
- **تحقق آلي:** اختبار أو مدقق يثبت الخاصية البرمجية المحددة فقط؛ لا يثبت الدلالة ما لم يُكتب الاختبار لقياسها فعلاً.
- **غير محسوم/غير مفحوص:** الدليل الحالي لا يكفي. يظل البند مفتوحاً لإجراء بحث أو بناء فحص آلي أفضل، ولا يُعرض على أنه سليم.

لا تُستخدم عبارة «مراجعة بشرية»، «مختص راجع»، أو «اعتماد خبير» لوصف العمل الذي نفذه النموذج. وبالمقابل، لا تُشترط مراجعة بشرية غير متاحة لإتمام العمل: يمكن إغلاق بند ضمن نطاق الأدلة المسجلة، مع إبقاء حدود ذلك النطاق معلنة.

## ما لا تثبته هذه الطريقة

- اجتياز الاختبارات لا يضمن خلو كل مادة من الأخطاء، ولا يثبت إتقان المتعلم.
- معرفة النموذج أو نتيجة بحث منفردة ليست مرجعاً بحد ذاتها؛ الحقائق الجوهرية تُسند إلى روابط واضحة، وما يتعذر توثيقه يظل مقيداً أو مفتوحاً.
- فحص ملف صوتي أو تفريغه نصياً لا يثبت وحده طبيعية النطق أو جودة التنغيم. إذا لم تتوفر أداة سمعية/صوتية قابلة للتقييم، يُذكر ذلك صراحة ولا يُختلق تقييم.
- لا يُدّعى اعتماد CEFR/Goethe أو الاستعداد للامتحان الرسمي دون دليل يطابق معيار الادعاء؛ تُوصف التغطية بأنها مقارنة تعليمية موثقة ضمن النطاق فقط.

## أثر التوثيق

يُسجل في `docs/LESSON-REVIEW-TRACKER-AR.md` لكل دفعة: الملفات المقروءة، البنود التي عُدلت، روابط المصادر وتاريخ الوصول، الاختبارات، والحدود التي بقيت. وتُربط التغييرات بالملفات والاختبارات الفعلية. لا تُستخدم حالات «بانتظار خبير» أو «بانتظار مراجعة بشرية» كحالات إنجاز.
