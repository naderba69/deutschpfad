# DeutschPfad — درب الألمانية

منصة تدريب ذاتي باللغة الألمانية للناطقين بالعربية، بمواد وتمارين ضمن نطاقات A1–B2. بعض الموضوعات والمهام مستلهمة من أوصاف CEFR وأنماط Goethe، لكن المنصة ليست معتمدة من Goethe-Institut ولا تقدم اختبار CEFR معيارياً أو شهادة رسمية. نتائج التمارين والتقييمات الداخلية لا تثبت مستوى اللغة أو الجاهزية لامتحان خارجي.

> **حالة المشروع:** قيد التدقيق والتحسين؛ لا يعني نجاح البناء أو الاختبارات أن جميع الواجهات والمحتويات قد دُققت أو أن المنتج جاهز للإطلاق العام. راجع [سجل التدقيق](docs/PROJECT-AUDIT-2026-11-04-AR.md) و[مسار الإصلاح والإنتاج](docs/REPAIR-AND-RELEASE-PLAN-AR.md).

## المتطلبات والتشغيل

- Node.js 22 (الإصدار المحدد في `.nvmrc`؛ يتطلب المشروع Node.js 20.9 أو أحدث بحسب `package.json`).
- npm، مع تثبيت الاعتماديات من `package-lock.json` باستخدام `npm ci`.

```bash
npm ci
npm run dev
```

ثم افتح `http://localhost:3000` في بيئة التطوير المحلية.

## أوامر التحقق

```bash
npm run lint
npm run typecheck
npm test -- --run
npm run build
npm run test:e2e
```

تتطلب اختبارات E2E تثبيت متصفح Playwright (Chromium). راجع `playwright.config.ts` وإعداد CI؛ تعداد الاختبارات وحده لا يشغلها. نفّذ الأوامر بالتتابع، خصوصاً typecheck وbuild، لأن Next.js يعيد توليد ملفات الأنواع أثناء البناء.

لجرد مساعد للمحتوى:

```bash
npm run audit:curriculum
```

هذا الجرد آلي/نصي ولا يعد مراجعة لغوية أو بيداغوجية بشرية.

## ملاحظات المنتج والبيانات

- بعض بيانات التقدم تحفظ محلياً في المتصفح؛ لا تفترض وجود حساب أو مزامنة بين الأجهزة. راجع واجهة إعدادات البيانات وسياسة الخصوصية قبل إدخال بيانات حساسة.
- خصائص الذكاء الاصطناعي قد تعتمد على خدمات خارجية وإعدادات بيئية اختيارية. لا تضف مفاتيح API أو أسراراً إلى ملفات Git؛ استخدم إعدادات بيئة النشر.
- الاختبارات السريعة، العتبات، الشارات، والشهادات الداخلية لأغراض التدريب وتتبع نشاط المنصة فقط، ولا تمثل قياساً معيارياً أو اعتماداً خارجياً.
