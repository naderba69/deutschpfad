# 🎓 درب الألمانية — DeutschPfad

منصة تعليمية عربية متكاملة لتعليم **اللغة الألمانية من الصفر (A1) حتى الاحتراف (B2)**
وفق منهجية معهد غوته (Goethe-Institut) ومعايير الإطار الأوروبي المرجعي المشترك للغات (CEFR)،
بتصميم يحاكي الأستاذ الخصوصي بالكامل — تعمل **كبديل كامل** عنه.

> ✅ **حالة المشروع: مكتمل وجاهز للنشر.** اكتملت المراحل الـ16 كلها: المحتوى الأكاديمي كاملاً (A1→B2)،
> أنظمة التعلم الذكي، والمراجعة النهائية الشاملة (تدقيق لغوي + كود + أداء + وصولية + استجابة + توثيق + نشر).
> المستخدمون الأوائل على **Vercel** (الأساسي) و**Render** (الاحتياطي).

## 🚀 التشغيل محلياً

```bash
# 1) التثبيت
npm install

# 2) التطوير (مع HMR)
npm run dev
# → http://localhost:3000

# 3) البناء الإنتاجي (يولّد أيضاً الـ Service Worker + الـ PWA)
npm run build

# 4) تشغيل النسخة الإنتاجية (جرّب وضع Offline في DevTools!)
npm start
```

أوامر إضافية:

```bash
npm run typecheck   # فحص الأنواع (TypeScript)
npm run lint        # فحص الكود (ESLint)
```

### 📚 المحتوى الأكاديمي — المستوى A2 (المرحلة 7)

**12 درساً كاملاً** بنفس قالب A1 + **ميزة المراجعة التراكمية (Interleaving)**: كل درس يبدأ بـ 3 أسئلة من A1 لتنشيط المعرفة القديمة:

| الدرس | المحور النحوي |
|---|---|
| A2-01 | السفر والعطلات: **Perfekt** (haben/sein + Partizip II) |
| A2-02 | الصحة: أجزاء الجسم + **sollen** (النصيحة) |
| A2-03 | المطعم: **möchten/können** + schmecken + lecker |
| A2-04 | البحث عن سكن: **Wechselpräpositionen** (wo? Dativ / wohin? Akkusativ) |
| A2-05 | المكتب: **Präteritum** (war/hatte) + لغة الهاتف والبريد الرسمي |
| A2-06 | الإعلام: **dass** (الفعل في نهاية الجملة الثانوية) + الرأي |
| A2-07 | البنك: **es gibt + Akkusativ** + ضمائر النصب والجر (mich/dir...) |
| A2-08 | المواصلات: **Komparativ/Superlativ** + الشواذ + التذاكر |
| A2-09 | المناسبات: **Dativ الكامل** + أفعاله (helfen, gefallen, gehören, gratulieren) |
| A2-10 | المدرسة: **weil/wenn/ob** + الضمائر الملكية في كل الحالات |
| A2-11 | الخدمات: **الأفعال الانعكاسية** (sich freuen, sich anmelden...) |
| A2-12 | العلاقات: **أدوات الربط** (aber/deshalb/trotzdem/dann) + المشاعر |

+ **بنك مفردات A2 (~250 كلمة)** في `src/data/vocabulary/a2.ts`
+ **«كلمة اليوم» حية** في الصفحة الرئيسية من بنك A1 (تتغير يومياً)

### 📚 المحتوى الأكاديمي — المستوى B1 (المرحلة 8)

**10 دروس كاملة** — مستوى الانتقال للاستقلالية:

| الدرس | المحور النحوي |
|---|---|
| B1-01 | التعليم: **Genitiv** (des Lehrers) + **Relativsätze** (der/die/das) |
| B1-02 | العمل: **Präteritum الكامل** + **Plusquamperfekt** (hatte gearbeitet) |
| B1-03 | البيئة: **Passiv** (wird/wurde + Partizip II) + man |
| B1-04 | الإعلام: **Konjunktiv II** (würde/wäre/hätte/könnte) |
| B1-05 | الصحة: **Konjunktiv II في الماضي** (hätte + Partizip II) + als ob |
| B1-06 | الثقافة: **Adjektivdeklination** (تصريف الصفات) |
| B1-07 | السياسة: **الجمل الزمنية** (als/wenn/während/bevor/nachdem/bis) |
| B1-08 | التقنية: **Futur I** (werden + Infinitiv) + **الروابط المزدوجة** (nicht nur... sondern auch...) |
| B1-09 | التطوع: **Nomen-Verb-Verbindungen** + **n-Deklination** |
| B1-10 | المستقبل: **جمع قواعد B1** في جمل مركبة (مراجعة شاملة) |

+ **جدول الأفعال الشاذة التفاعلي** (بحث + فلترة + نطق — 60+ فعلاً) مدمج في دروس B1/B2
+ **اختبار تحديد المستوى** (`/placement`): 15 سؤالاً عشوائياً (5 A1 + 5 A2 + 5 B1) بنتيجة ومستوى البدء — نواة نظام الاختبارات
+ **بنك مفردات B1 (~200 كلمة)** في `src/data/vocabulary/b1.ts` — الإجمالي ~750 كلمة

### 📚 المحتوى الأكاديمي — المستوى B2 (المرحلة 9) — اكتمال المحتوى

**10 دروس كاملة** — قمة المستويات الأربعة:

| B2-04 | الأدب: **Partizip I/II كصفات** (das spielende Kind) |

| B2-09 | سوق العمل: **Nomen-Verb-Verbindungen المتقدمة** + المراسلات الرسمية |

### 🤖 الأدوات الذكية المتقدمة (المرحلة 11)

**صفحة `/ai-tools`** — 9 أدوات مدعومة بـ LLM (تُخفى تلقائياً عند غياب المفاتيح):

| الأداة | الوظيفة |
|---|---|
| اسأل المعلّم | سؤال حر عن أي شيء بالألمانية مع شرح وأمثلة |
| مصحح الكتابة الذكي | يحلل فقرة ويشرح كل خطأ بالعربية + تصنيف النوع + اقتراح درس |
| تقييم مستوى الكتابة (CEFR) | يقدر مستوى فقرة حرة (A1-B2) بالمعايير وخطة تقدم |
| مولّد التمارين اللامنتهي | تمرين جديد كامل (مستوى + قاعدة + نوع) بالحل والشرح |
| مولّد الجمل السياقية | كلمة → 5 جمل متدرجة الصعوبة مع الترجمة والسياق |
| مولّد القصص المخصصة | قصة بمفردات مستوى المستخدم فقط (Comprehensible Input) |
| المترجم الذكي السياقي | ترجمة دقيقة + شرح «لماذا» تختلف عن الحرفية + بدائل |
| حلّل أخطائي في آخر اختبار | المعلّم يقرأ آخر نتيجة اختبار محفوظة ويخطط تقويتك |
| التقرير الأسبوعي الذكي | يحلل نشاطك ونمط أخطائك من بياناتك المحفوظة + خطة أسبوع |

+ **قوالب برومبتات مركزية** في `src/lib/llm/prompts.ts` (نظام تعليمي موحد)
+ **غلاف موحد** `AiToolShell`: زر + تحميل + نتيجة + احترام الحصة اليومية
+ **نتائج الاختبارات تُحفظ تلقائياً** (IndexedDB) لتغذية «حلّل أخطائي» والتقرير الأسبوعي
+ **الاختبار الأسبوعي التجميعي** (`/tests/weekly`): يخلط المستويات الأربعة بتركيز متجدد أسبوعياً (اقتراح)
+ زر «لم أفهم — اشرح بطريقة أخرى» (من المرحلة 6) يعمل بنفس النظام

### 🔍 المراجعة النهائية (المرحلة 16) — الجودة والأداء والوصولية

**التدقيق اللغوي:** فحص آلي لجميع ملفات المحتوى — لا اقتباسات ألمانية مفتوحة، لا أخطاء ß/ss،
الأسماء الألمانية بأحرف كبيرة صحيحة، وكتابة عربية سليمة (45 درساً + 950 مفردة + المراجع).

**تدقيق الكود:** `tsc --noEmit` ✅ + `eslint` ✅ (مفعّل الآن أثناء البناء — أي خطأ يوقف النشر).

**الأداء (أرقام البناء الفعلية):**
- صفحات الاختبارات والمساعد الذكي: **تحميل كسول كامل** (`next/dynamic`) — لا تُحمَّل بنوك الأسئلة ومحركات الاختبار إلا عند فتح الاختبار
- `/learning-path`: 340 KB → **147 KB** أول تحميل (−57%) بفضل فهرس الدروس الخفيف `data/lessons/meta.ts`
- `/dashboard/five-minutes`: 330 KB → **137 KB** (−58%)
- عزل بيانات الدروس الكاملة في حزمة خاصة تُحمَّل فقط عند اختبار الوحدة
- **ضغط** gzip/brotli + **رؤوس كاش** ذكية (`immutable` للأيقونات، ساعة لصفحة offline) + إخفاء `X-Powered-By`
- **Service Worker**: كاش `CacheFirst` للأصول الثابتة وملفات `_next/static` (30 يوماً) + تنقل `NetworkFirst` + صفحة Offline

**الوصولية (WCAG):**
- رابط «تخطَّ إلى المحتوى» + `id="main-content"` + حلقة تركيز `:focus-visible` عامة + احترام `prefers-reduced-motion`
- تباين ألوان مُصلَح آلياً: ذهبي نصي جديد `gold-strong` (AA 4.5:1) وأخضر نجاح أغمق `success` (AA 4.95:1)
- لا صور بلا `alt`، لا عناصر قابلة للنقر غير أزرار، كل الأزرار بنصوص عربية واضحة

**الاستجابة (Responsive):** لا عروض ثابتة كبيرة، كل الشبكات لها بدائل استجابة، الجداول داخل `overflow-x-auto`،
وكل الصفحات الـ86 تُختبر على الجوال.
