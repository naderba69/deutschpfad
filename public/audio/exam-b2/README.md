# مقاطع صوت الاستماع لامتحان B2 (`public/audio/exam-b2`)

البنية: `<النموذج a|b|c>/<اسم الملف>.mp3` — **14 ملفاً لكل نموذج**.

| الجزء | أسماء الملفات |
|---|---|
| Teil 1 (5 حوارات) | `hoeren-t1-g1.mp3` … `hoeren-t1-g5.mp3` |
| Teil 2 (مقابلة) | `hoeren-t2.mp3` |
| Teil 3 (7 إعلانات) | `hoeren-t3-a1.mp3` … `hoeren-t3-a7.mp3` |
| Teil 4 (حديث طويل) | `hoeren-t4.mp3` |

- النصوص الكاملة المطلوب تسجيلها: `docs/B2-EXAM-AUDIO-PRODUCTION.md`
- المواصفات: MP3 أحادي 44.1 kHz · 56 kbps — `ffmpeg -i in.wav -ac 1 -ar 44100 -b:a 56k out.mp3`
- حتى تكتمل ملفات نموذج، يقرأ الامتحان نصه بنطق آلي (TTS) ويخبر المتعلم بذلك.
- **لا ترفع نصف نموذج**: حارس الأصول (`src/data/audio-assets.test.ts`) يفشل إن كان
  مجلد نموذج فيه مقاطع ناقصة أو تالفة.
